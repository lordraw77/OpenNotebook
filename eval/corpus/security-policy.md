# Corporate Wireless Security Policy (WSP-2026)

1. Every access point must use WPA3 with SAE (Simultaneous Authentication of Equals). WPA2 is allowed only on
   isolated guest networks and must be retired by 31 December 2026.
2. Management interfaces must only be reachable from the management VLAN 900, never from user VLANs.
3. Firmware must be updated within 30 days of a security release. Access points older than firmware 7.4 must
   be updated before being connected to the production network.
4. Every access point must be registered in the asset inventory with its serial number before deployment.
5. Exceptions require written approval from the Chief Information Security Officer.
